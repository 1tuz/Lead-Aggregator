# Design

## Цель

Простая desktop-утилита, а не CRM. Один основной сценарий: настроить запрос → запустить → увидеть таблицу → экспортировать.

## Макет

- Левая фиксированная колонка: параметры сбора и запуск.
- Основная область: состояние, экспорт, краткая статистика, таблица.
- Никаких вложенных страниц для v0.1.

## Токены

Все цвета живут в CSS custom properties. Есть две темы:

- `frost` — светлая;
- `graphite` — темная.

Компоненты не используют жестко заданные цвета состояния за пределами токенов.

## macOS

- системное окно Tauri;
- компактные элементы управления;
- 9–12 px радиусы элементов, 18 px контейнеров;
- небольшой blur как визуальный слой, без обязательной native vibrancy зависимости;
- Inter подключается локально через `@fontsource-variable`, без CDN.

## Доступность

- нормальные `label` для полей;
- клавиатурный focus остается видимым;
- состояние не кодируется только цветом;
- `prefers-reduced-motion` может быть добавлен при появлении заметных анимаций; сейчас анимации минимальны.
