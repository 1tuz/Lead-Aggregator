# Russian city directory

`russian-geography.json` contains the 1,117 Russian cities and 85 region names from the Rosstat-derived `ru-cities` dataset. The dataset documents its city list as sourced from Rosstat's *Regions of Russia: Main Socio-Economic Indicators of Cities* publication and its population estimates as of 2020.

- Dataset and extraction notes: https://github.com/epogrebnyak/ru-cities
- Rosstat publication: https://rosstat.gov.ru/folder/210/document/13206
- Source snapshot: `epogrebnyak/ru-cities` `main`, downloaded 2026-10-01

The directory is bundled with the app, so suggestions work offline. New city names or provider-specific URL slugs must be verified against their source catalogs before updating the data.
